Put the missing orders back into Firebase

Finds orders the Google Sheet has and Firebase does not, then checks each one against what Firebase already holds for that customer on nearby dates — so an order that was simply re-entered under a new id is never written twice.
Green = Firebase has nothing like it. Safe to write.
Red = Firebase already holds something very similar for that customer. Writing it would probably double-count. These start unticked, and the nearby order is shown so you can judge it yourself.

The Google Sheet is never touched. Orders you deliberately deleted are never resurrected.
